# Git в VS Code и терминале

В VS Code удобно:

1. Видеть текущую ветку и список изменённых файлов в панели Source Control.
2. Открывать diff файла и сразу видеть добавленные и удалённые строки.
3. Просматривать историю коммитов в разделе Graph.

В терминале удобнее задавать точные параметры команд, например `git log --oneline --all --graph`.
