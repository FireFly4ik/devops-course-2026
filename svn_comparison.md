# Сравнение Git и SVN

1. **Почему ветвление в Git считают дешёвым?** Ветка Git — это ссылка на коммит, которую можно создать локально без обращения к серверу. В SVN ветка обычно создаётся копированием каталога внутри центрального репозитория. Такое копирование тоже технически быстрое, но требует доступа к серверу; дальнейшая работа с веткой и слияние зависят от центрального репозитория.

2. **Можно ли сделать коммит в SVN без интернета?** SVN отправляет коммит в центральный репозиторий, поэтому нужен доступ к его серверу. Публичный интернет не обязателен, если сервер доступен по локальной сети. Если связи с сервером нет, коммит выполнить нельзя; локальные файлы можно продолжать редактировать.

3. **Когда SVN может быть предпочтительнее?** При поддержке существующего проекта, где история, процессы и права доступа уже настроены в SVN, а переход на Git не даёт достаточной выгоды. Также SVN подходит команде, которой нужен один центральный репозиторий и существующие инструменты работы с ним.
