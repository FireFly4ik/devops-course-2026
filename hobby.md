# Мой пет-проект

Идея: консольное приложение для учёта личных расходов. Пользователь добавляет покупку, категорию и сумму, а приложение показывает траты за месяц по категориям.

Стек: Python, SQLite.

Цель: научиться хранить данные в SQLite и строить простые отчёты по расходам.

Минимальный результат первой версии: пользователь может записать расход с категорией и суммой, а затем получить сводку расходов за выбранный месяц по категориям.
